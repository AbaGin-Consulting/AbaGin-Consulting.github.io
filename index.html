AbaGin Infisical Backup

AbaGin Infisical Backup is a private, self-hosted backup workflow used to store encrypted disaster-recovery copies of an Infisical deployment in Google Drive.

Google Drive access

The application uses the Google Drive API with the drive.file permission. This limits access to Google Drive files created by or explicitly used with this application. It does not request full access to all files in the connected Google Drive account.

Backup content is encrypted on the client side before it is uploaded to Google Drive. OAuth credentials and backup encryption credentials are not stored in this public website repository.

Purpose

The service is used only for backup, restore, integrity checking, and disaster recovery of the operator's self-hosted Infisical environment. It is not offered as a public consumer service.

Privacy

Details about Google API data access, retention, security, and revocation are available in the Privacy Policy.
